تشخيص أعطال الإنفرتر

ماذا أفعل عند ظهور كود العطل؟

E1 - خطأ اتصال

  • افصل الكهرباء 5 دقائق.
  • افحص سلك الإشارة بين الداخلي والخارجي.
  • قِس جهد التغذية.
  • افحص الفيش والتوصيلات.
  • إذا كانت التوصيلات سليمة افحص البوردة.

P0 - عطل IPM أو الإنفرتر

  • افحص عدم وجود شورت في الكباس.
  • افحص الـ IGBT.
  • افحص وحدة IPM.
  • قِس جهد الـ DC Bus.
  • افحص المكثفات الإلكترونية.

P1 - ارتفاع أو انخفاض الجهد

  • قِس الجهد الداخل.
  • تأكد أن الجهد بين 220 و240 فولت.
  • افحص القاطع والأسلاك.
  • ركب مثبت جهد إذا لزم الأمر.

P4 - زيادة تيار الكباس

  • قِس أمبير الكباس.
  • افحص ضغط الفريون.
  • افحص المكثف الخارجي.
  • افحص المروحة الخارجية.
  • افحص وجود شورت بالكباس.

EC أو F0 - نقص فريون

  • ابحث عن التسريب.
  • قم بإصلاح مكان التسريب.
  • اسحب فاكيوم.
  • اشحن الفريون بالوزن.

H3 - ارتفاع حرارة الكباس

  • افحص نظافة المكثف.
  • افحص مروحة الوحدة الخارجية.
  • افحص شحنة الفريون.
  • قِس أمبير الكباس.

H6 - عطل المروحة الداخلية

  • افحص موتور المروحة.
  • افحص حساس الهول إن وجد.
  • افحص الجهد الخارج من البوردة.
  • افحص الفيش والأسلاك.

E4 - ارتفاع حرارة الطرد

  • افحص شحنة الفريون.
  • افحص اتساخ المكثف.
  • افحص مروحة الوحدة الخارجية.
  • افحص حساس الطرد.

P7 - عطل مروحة الوحدة الخارجية

  • افحص موتور المروحة.
  • افحص مكثف المروحة إذا كان موجوداً.
  • افحص خرج البوردة.
  • افحص الفيش والأسلاك.
