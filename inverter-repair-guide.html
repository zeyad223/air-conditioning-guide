دليل إصلاح أعطال الإنفرتر

ابدأ التشخيص خطوة بخطوة

1- الجهاز لا يعمل نهائياً

  • افحص مصدر الكهرباء.
  • افحص الفيوز.
  • افحص جهد الدخول للبوردة.
  • افحص Bridge Rectifier.
  • افحص جهد الـ DC Bus.

2- الوحدة الداخلية تعمل والكباس لا يعمل

  • افحص الكود الظاهر على الشاشة.
  • افحص جهد الـ DC Bus.
  • افحص الـ IPM.
  • افحص الـ IGBT.
  • افحص مقاومات الكباس.

3- ظهور الكود P0

  • افحص وجود شورت في الكباس.
  • افحص الـ IPM.
  • افحص الـ IGBT.
  • افحص المكثفات.
  • افحص دائرة الـ Driver.

4- ظهور الكود P1

  • قِس الجهد الكهربائي.
  • تأكد أن الجهد بين 220 و240 فولت.
  • افحص الأسلاك والقاطع.

5- ظهور الكود EC أو F0

  • ابحث عن تسريب الفريون.
  • قم بإصلاح التسريب.
  • اسحب فاكيوم.
  • اشحن الفريون بالوزن.

6- ظهور الكود H3

  • افحص حرارة الكباس.
  • افحص نظافة المكثف.
  • افحص المروحة الخارجية.
  • افحص شحنة الفريون.

7- لا يوجد تبريد

  • افحص شحنة الفريون.
  • افحص الحساسات.
  • افحص سرعة الكباس.
  • افحص الضغوط.
  • افحص انسداد دائرة التبريد.

8- فصل القاطع الكهربائي

  • افحص وجود شورت في الكباس.
  • افحص الـ IGBT.
  • افحص الـ IPM.
  • افحص Bridge Rectifier.

قاعدة مهمة

لا تقم بتغيير لوحة الإنفرتر أو الـ IPM قبل التأكد من سلامة الكباس، لأن وجود شورت بالكباس قد يؤدي إلى تلف البوردة الجديدة فور تشغيلها.
